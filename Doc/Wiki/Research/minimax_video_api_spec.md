# MiniMax Video-01 API 技術仕様・制約まとめ

## 概要
MiniMax社（Hailuo AI）が提供する動画生成API「Video-01」に関する技術仕様、呼び出しフロー、および本プロジェクトでの制約事項の調査結果です。

---

## 1. 主要スペック
- **解像度**: 720p (1280x720 または 720x1280 縦動画)
- **フレームレート**: 25 fps
- **クリップ秒数**: 約6秒
- **対応モード**: Text-to-Video (T2V), Image-to-Video (I2V)
- **特徴**: シネマティックなカメラワークへの追従性が高く、人物の動きの破綻が比較的少ない。

---

## 2. APIフロー（非同期タスク方式）
1. **タスク投入 (`POST /v1/video_generation`)**:
   - `prompt`（プロンプトテキスト）およびモデル指定 `model="video-01"` を送信。
   - レスポンスとして一意な `task_id` を受け取る。
2. **ステータスポーリング (`GET /v1/query/video_generation?task_id={task_id}`)**:
   - `Processing`（処理中）、`Success`（成功）、`Fail`（失敗）を監視。
3. **動画取得**:
   - 完了時にダウンロード用URL（有効期限付き）または `file_id` が返却される。
   - URLの失効前にローカルキャッシュ（`temp/clips/`）へダウンロードして保存する。

---

## 3. 実装上の注意点
- **レートリミット**: 連続リクエストによる429 Too Many Requestsを避けるため、同時実行は最大2リクエストに制限し、指数バックオフを実装する。
- **エラーハンドリング**: セーフティフィルターによる生成拒絶（コンテンツ違反）時には、プロンプトを緩和して再試行する。
